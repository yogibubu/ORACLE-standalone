# ORACLE standalone package

This folder contains the final revised manuscript, marked manuscript,
Supporting Information, and response to the referees. The `submission/`
subdirectory is self-contained and contains the clean manuscript source,
bibliography, and all figures, including the TOC graphic.

Compile from `submission/` with:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error revised_clean.tex
```
